# PDF Maker

Небольшое desktop-приложение на Python: заменяет первый лист одного PDF-файла
листом из другого PDF-файла (в котором ровно одна страница) и сохраняет
результат в третий PDF-файл.

## Возможности

- Аккуратный графический интерфейс на Tkinter (входит в стандартную
  библиотеку Python, ничего дополнительно ставить не нужно).
- Файлы можно выбрать кнопкой «Обзор…» или просто перетащить из Проводника
  в нужное поле (используется `tkinterdnd2`).
- Папка сохранения выбирается один раз и запоминается между запусками —
  дальше нужно вводить только имя нового файла.
- Проверка входных данных: файл замены должен содержать ровно 1 страницу,
  исходный файл — хотя бы 1 страницу; подтверждение перед перезаписью
  существующего файла.
- Понятные сообщения об ошибках и кнопка «Открыть папку» после сохранения.
- Ядро логики (`pdf_maker/core.py`) не зависит от GUI и покрыто тестами —
  им можно пользоваться и из своих скриптов.

## Установка

Требуется Python 3.9+.

```bash
pip install -r requirements.txt
```

## Запуск GUI

```bash
python main.py
```

В открывшемся окне:

1. **Исходный PDF** — многостраничный файл, у которого нужно заменить
   первый лист.
2. **Новый лист (PDF, ровно 1 страница)** — файл, содержащий ровно одну
   страницу, которая станет новой первой страницей результата.
3. **Папка сохранения** — куда сохранить результат; выбирается один раз
   кнопкой «Изменить папку…» и запоминается для следующих запусков.
4. **Имя нового файла** — просто имя файла (например, `result.pdf`);
   расширение `.pdf` добавится автоматически, если его не указать.

Нажмите **«Заменить и сохранить»** — приложение соберёт итоговый документ
(новая первая страница + все страницы исходника, начиная со второй) и
сохранит его в указанной папке под указанным именем. Если файл с таким
именем уже существует, будет запрошено подтверждение перезаписи.

## Использование как библиотеки

```python
from pdf_maker.core import replace_first_page

replace_first_page(
    source_pdf="document.pdf",
    replacement_pdf="new_first_page.pdf",
    output_pdf="result.pdf",
)
```

## Сборка .exe (Windows)

Приложение можно собрать в один самостоятельный `.exe`, который запускается
без установленного Python — удобно раздавать другим людям.

```bash
pip install -r requirements-dev.txt
pyinstaller PdfMaker.spec
```

Готовый файл появится в `dist/PdfMaker.exe`. Это GUI-приложение — консольное
окно при запуске не открывается. Папки `build/` и `dist/` создаются локально
и не хранятся в git (см. `.gitignore`) — при необходимости просто соберите
`.exe` заново командой выше.

Если нужно поменять настройки сборки (например, добавить иконку), правьте
`PdfMaker.spec` и пересобирайте той же командой — так сборка остаётся
воспроизводимой и не требует запоминать флаги `pyinstaller`.

## Структура проекта

```
pdf-maker/
├── main.py               # точка входа: запуск GUI
├── PdfMaker.spec         # конфигурация сборки .exe (PyInstaller)
├── pdf_maker/
│   ├── core.py            # логика замены страницы (без GUI)
│   ├── gui.py             # окно на Tkinter
│   └── config.py          # запоминание папки сохранения между запусками
├── tests/
│   └── test_core.py       # unit-тесты
├── requirements.txt       # зависимости для запуска приложения
└── requirements-dev.txt   # + зависимости для тестов и сборки .exe
```
