# PDF Maker

Небольшое desktop-приложение на Python: заменяет первый лист одного PDF-файла
листом из другого PDF-файла (в котором ровно одна страница) и сохраняет
результат в третий PDF-файл.

## Возможности

- Простой графический интерфейс (Tkinter, входит в стандартную библиотеку Python).
- Проверка входных данных: файл замены должен содержать ровно 1 страницу,
  исходный файл — хотя бы 1 страницу.
- Понятные сообщения об ошибках.
- Ядро логики (`pdf_maker/core.py`) не зависит от GUI и покрыто тестами —
  им можно пользоваться и из своих скриптов.

## Установка

Требуется Python 3.9+.

```bash
pip install -r requirements.txt
```

## Запуск GUI

```bash
python main.py
```

В открывшемся окне:

1. **Исходный PDF (документ)** — многостраничный файл, у которого нужно
   заменить первый лист.
2. **PDF с новым листом (1 страница)** — файл, содержащий ровно одну
   страницу, которая станет новой первой страницей результата.
3. **Сохранить результат как** — путь для нового (третьего) PDF-файла.

Нажмите **«Заменить и сохранить»** — приложение соберёт итоговый документ:
новая первая страница + все страницы исходника, начиная со второй.

## Использование как библиотеки

```python
from pdf_maker.core import replace_first_page

replace_first_page(
    source_pdf="document.pdf",
    replacement_pdf="new_first_page.pdf",
    output_pdf="result.pdf",
)
```
